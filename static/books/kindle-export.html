📑 从 Kindle 导入标注

亚马逊没有开放接口，这个小工具直接在你自己的浏览器里读取 read.amazon.com/notebook 页面，把每本书的标注抓成 JSON 文件。再用书架页的「导入恢复」吃进去就行，全程不经过第三方服务器。

步骤（在电脑浏览器上操作，手机不好拖书签）

  1. 把这个按钮拖到浏览器书签栏：
    📑 导出 Kindle 标注
  2. 打开 read.amazon.com/notebook，用你的美区 Amazon 账号登录
  3. 点击书签栏上的「📑 导出 Kindle 标注」，保持标签页打开，等它逐本抓完（书多要几分钟），会自动下载 kindle-notebooks-日期.json
  4. 把下载的 JSON 发给我，我来转好直接推进你的云端书架；或者在书架页点「导入恢复」选这个文件，页面会自动识别 Kindle 格式

备选：复制代码

如果书签栏拖不出来，点 ，然后在 notebook 页面按 ⌘⌥J（Mac Chrome）打开控制台，粘贴回车，效果一样。

说明

  • 只能导出亚马逊云端已同步的标注；国区 Kindle 商店已关，国区账号没有云端数据
  • 部分图书因出版商导出限制，个别标注可能抓不到，工具会如实报告
  • 你写在标注旁边的个人备注这个工具导不出，只能导出标注原文
  • 导出脚本来自开源项目 dylanjcastillo/blog（MIT 风格的个人工具），仅在你的浏览器本地运行
